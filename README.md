## 🌐 Live Website

[Visit My Portfolio](https://wkinc.github.io/portfolio/)

## 🛠️ Technologies Used

- HTML
- CSS

## 📂 Website Sections

- **Projects** – Personal and academic projects.

- Simple navigation.
